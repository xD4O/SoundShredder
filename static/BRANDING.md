# Branding assets

- Creator: **cyr4x**. Social destinations supplied by the creator: [X](https://x.com/_cyr4x), [Higgsfield](https://higgsfield.ai/@cyr4x), [Instagram](https://www.instagram.com/__cyr4x__/), [YouTube](https://www.youtube.com/@cyr4xfilms).
- `higgsfield-mark.svg`: Higgsfield's navigation glyph, taken from the public [Higgsfield website](https://higgsfield.ai/) on 2026-09-16. Geometry is unchanged; the SVG namespace and a light fill were added for a standalone image on this dark interface.
- The Higgsfield navigation wordmark was verified as **Space Grotesk, weight 700** using the site's computed style. The interface uses that font for its Higgsfield wordmark and creator signature.
- `fonts/SpaceGrotesk-Variable.ttf`: [Google Fonts' Space Grotesk distribution](https://github.com/google/fonts/tree/main/ofl/spacegrotesk), under the SIL Open Font License. The complete license is included at `fonts/SpaceGrotesk-OFL.txt`.

Logo and font files are bundled locally. Displaying the interface does not contact social sites or a font CDN; links open their destinations only when clicked.
