# Mac standalone 1.1.1 — native reopening and reliable relaunch

This update replaces the old shell-only app entry point with a native macOS AppKit launcher. It addresses the reported **“SoundShredder is not open anymore”** message when reopening an already-running app.

Choose your download from **Apple menu → About This Mac**:

- **SoundShredder-1.1.1-Mac-AppleSilicon.zip** — M-series Macs.
- **SoundShredder-1.1.1-Mac-Intel.zip** — Intel Macs.

Requires **macOS 12 or newer**. Python is included; the CPU engine installs automatically. No Homebrew, separate Python installation or terminal setup is required.

## Open, close and return

1. **Upgrading from 1.1.0:** first select **Close SoundShredder** in the old setup page. Wait for it to close, then replace SoundShredder.app in Applications. Keep the support folder, engines, sessions and model caches.
2. Extract the matching ZIP and move **SoundShredder.app** into Applications or `~/Applications`.
3. Open it normally. First use guides engine installation; subsequent launches reuse your installed engine and sessions.
4. Open the app again while it is running to return to your workspace. Native macOS reopening is handled by the existing app.
5. Use the waveform icon in the menu bar for **Open SoundShredder**, **Setup and diagnostics**, or **Quit SoundShredder**. The setup screen also has **Close SoundShredder**.
6. After quitting, reopen SoundShredder from Applications whenever you want to return. Closing a browser tab alone keeps the app running.

The app also verifies saved local addresses, recovers from stale launch metadata and stopped workspace processes, avoids hostname lookups during local setup startup, and retains explicit certificate settings. The same web interface, video preview, presets, multi-pass bubble cleanup and isolated-track downloads remain available.

## Verification

Native GitHub CI runners for **Apple Silicon and Intel** each completed first CPU-engine installation and four launch/reopen/close cycles through macOS Launch Services, including the native Quit action and launching again afterward. Duplicate opens reused the same manager. Platform launcher regression tests also passed. [Mac lifecycle run](https://github.com/xD4O/SoundShredder/actions/runs/35163101533).

These checks validate launch and engine health, not subjective audio quality or model inference. Consumer download/quarantine/Gatekeeper behavior and real Mac audio inference remain to be tested. The app has **no Developer ID signing or notarization** and remains an experimental prerelease. macOS may block an untrusted download; do not disable Gatekeeper globally.

Allow **3 GiB free for setup**, plus model/session storage. Processing is **CPU only**; Apple Metal/MPS is not enabled. First setup/model use needs internet. Package-install cancellation and automatic preview updates are not implemented. See **MAC-INSTALL.md** for complete instructions, troubleshooting and uninstall steps. **SHA256SUMS.txt** provides download checksums.
