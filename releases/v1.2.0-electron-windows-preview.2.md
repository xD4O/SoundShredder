# SoundShredder 1.2.0 — Windows Electron preview 2

The Windows app now makes its included uninstaller easier to find.

- Search Start for **Uninstall SoundShredder**, or use **SoundShredder > Uninstall SoundShredder…** in the app to open Windows Settings.
- The uninstall wizard explains what is removed and what stays. It removes the application and shortcuts while keeping saved sessions, downloaded engines, model caches and exported audio.
- The bundled Windows guide includes uninstall, reinstall and optional profile-removal instructions.

## Install or update

Download **SoundShredder-Electron-1.2.0-Windows-x64-Setup.exe** below. Finish or cancel any processing, quit SoundShredder, then run the EXE. An existing compatible engine and saved sessions can be reused. You do not need to uninstall the previous Electron preview first.

Windows 10/11 x64 is required. Choose CPU or a compatible NVIDIA GPU during first setup. Python is bundled; the audio engine and models download automatically. Allow at least 4 GiB free for CPU setup or 14 GiB for NVIDIA, plus room for the app, models and media.

## Files

- **EXE:** the Windows installer, including its uninstaller and offline instructions.
- **WINDOWS-INSTALL.md:** matching Windows installation, troubleshooting and removal guide.
- **SHA256SUMS.txt:** checksums for the installer and guide.

This is an unsigned Windows prerelease. The app may trigger a Windows publisher/SmartScreen prompt. This release does not change Mac downloads or Apple signing status.
