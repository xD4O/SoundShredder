# Choose where SoundShredder keeps your files

The Windows installer lets you choose the **application folder**. Now the desktop app also lets you choose a drive for the larger **audio engines, models, sessions and temporary setup downloads**.

1. Quit your current SoundShredder desktop app and run `SoundShredder-Electron-1.2.2-Windows-x64-Setup.exe`.
2. In setup, select **Choose folder…**, or use **SoundShredder > Choose storage folder…** later.
3. Pick a writable local or attached drive. SoundShredder creates its own folder there and remembers it after you close, reopen or update.

**Existing files stay where they are.** Choosing an empty folder starts a separate engine/session setup and can require new downloads. Select your old SoundShredder folder to return to its saved work. App preferences remain in the small default profile. Uninstalling keeps your data.

If a drive is disconnected, the recovery screen offers Retry opening or another folder. It will not silently download everything to C:. Folder checks and switching keep the interface responsive; active setup/audio work must finish or be canceled first. This release also fixes startup errors hidden behind “Opening…” and close requests during folder switching.

Includes the matching **WINDOWS-INSTALL.md**, an offline installation guide in Help, and **SHA256SUMS.txt**. CPU and NVIDIA choices, live setup progress, cancellation, track downloads and video preview remain available. Windows 10/11 x64; no separate Python or terminal setup required.
