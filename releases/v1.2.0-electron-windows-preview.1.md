## Install, create, return

1. Quit any earlier standalone using **Close SoundShredder** in its setup screen. Keep the existing engine and session folders.
2. Run the installer on **Windows 10/11 x64**. Choose the application folder and finish setup. Python is included; no separate terminal/Python setup is required.
3. Open **SoundShredder** from the Start menu or desktop. Select CPU or NVIDIA for automatic engine setup. Existing compatible engines and sessions are reused.
4. Drop your video/audio, choose a preset, and listen to/download the cleaned mix or isolated tracks. Video preview remains optional. Save dialogs let you choose export locations.
5. Close the window or choose **SoundShredder > Quit SoundShredder**, then launch normally whenever you return. Active setup/audio jobs must finish or be cancelled before quitting. Opening the shortcut twice brings the existing window forward.

Use **SoundShredder > Setup and diagnostics** for engine settings, **Workspace** to return, or **Open logs folder** for troubleshooting. A failed engine can be retried; owner-pipe cleanup stops background audio processes if the desktop host crashes.

Allow **4 GiB free for CPU** or **14 GiB for NVIDIA**, plus the desktop app, model downloads and saved media. The engine and models download automatically on first use; this is not a full offline engine installer. Processing stays local and works offline after the required files are cached.

The installer was also installed and reinstalled locally, with its Start menu shortcut checked. Shared regressions passed 173 Python tests and three Electron boundary tests. This is an **unsigned prerelease**. Windows may show a publisher/SmartScreen warning. Broader clean-PC and GPU validation remain ongoing. Checksums are included. Updates are manual through **Help > Check for Electron updates**; the workspace sidebar continues checking stable source releases.

The previous browser-based standalone and stable source releases remain available. The new Start menu shortcut opens Electron. Sessions and engines are stored separately from app files and are retained when upgrading or uninstalling the app.
