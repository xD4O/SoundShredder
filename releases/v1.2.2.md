# SoundShredder 1.2.2 — Windows & Mac desktop

The current SoundShredder desktop downloads, together in one release. Python is included, engine setup runs inside the app, and the familiar workspace stays local to your computer.

Mac requires **macOS 13 or newer**. Both Mac builds are **Developer ID signed and Apple-notarized**. ZIP alternatives: [Apple Silicon](https://github.com/xD4O/SoundShredder/releases/download/v1.2.2/SoundShredder-Electron-1.2.2-macOS-arm64.zip) · [Intel](https://github.com/xD4O/SoundShredder/releases/download/v1.2.2/SoundShredder-Electron-1.2.2-macOS-x64.zip). [SHA-256 checksums](https://github.com/xD4O/SoundShredder/releases/download/v1.2.2/SHA256SUMS.txt) cover all installers and attached guides.

**Windows:** run the EXE, choose the application folder, and open SoundShredder from Start. **Mac:** open the matching DMG, drag SoundShredder into Applications, eject the disk image, and launch from Applications.

In setup, optionally choose a folder for engines, models and sessions, then select **Set up SoundShredder**. No separate Python installation or Homebrew is needed. Initial engine/model downloads require internet; cached processing works offline. Windows offers CPU or compatible NVIDIA GPU processing; Mac uses CPU.

## What you get

- Drop in video or audio and reduce unwanted dialogue, music or effects using presets.
- Target water bubbles with optional aggressive multi-pass cleanup.
- Toggle video preview while comparing the original, cleaned mix, isolated tracks and removed sounds.
- Download audio mixes and individual tracks, then reopen saved sessions later.
- Choose where larger files live, follow setup progress, cancel/retry setup, and recover when a selected drive is unavailable.
- Quit and reopen the desktop app with saved sessions retained; Windows includes uninstall entries.

## Updating

This release makes **1.2.2** the repository's **Latest** version, replacing 1.0.3 as the default download. It uses the same verified installer bytes as the separate Windows and signed Mac 1.2.2 releases. If you already installed one of those 1.2.2 builds, **you do not need to reinstall**.

**Help → Check for Electron updates** opens releases. The sidebar's **Check for updates** now recognizes this published version. Updates remain manual: quit, install the newer Windows EXE or replace the Mac app, then reopen. Existing sessions and compatible engines are retained.

Prefer the browser interface? [Download the v1.2.2 source ZIP](https://github.com/xD4O/SoundShredder/archive/refs/tags/v1.2.2.zip) and follow the [Windows or Mac browser setup](https://github.com/xD4O/SoundShredder#run-the-web-app-locally). Source use still requires Python.
