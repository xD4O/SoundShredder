# SoundShredder 1.2.1 — Windows Electron preview

First setup now shows what is happening and lets you stop and retry without losing saved sessions.

- **Live progress:** see the current package, downloaded bytes, average download speed and elapsed time. Overall setup stages and individual downloads have separate bars.
- **Cancel and return:** Cancel setup stops the installer. Closing during setup offers Continue setup or Cancel setup and quit. Reopen and select Set up SoundShredder to repair an interrupted engine; some packages may download again.
- **Recover from stalls:** bounded network retries, installer inactivity/time limits and a workspace startup deadline turn stalled work into an actionable error. Diagnostics and status polling run independently, with a reconnection message when needed.
- **Reuse completed setup:** compatible engines and saved sessions remain available after closing, updating or reinstalling. The Windows uninstaller remains available in Start and Windows Settings.

## Install or update

Download **SoundShredder-Electron-1.2.1-Windows-x64-Setup.exe** below. Finish or cancel audio processing, quit SoundShredder, then run the EXE. You can install over the previous Electron preview; keep your separate profile folder to reuse its engine and sessions.

Windows 10/11 x64 is required. Python is bundled. Choose CPU or a compatible NVIDIA GPU during first setup; the engine and models download automatically. Allow at least 4 GiB free for CPU setup or 14 GiB for NVIDIA, plus room for the app, models and media.

The matching **WINDOWS-INSTALL.md** covers installation, cancellation, recovery and removal. **SHA256SUMS.txt** contains installer and guide checksums. The same Windows guide is included inside the app under Help.
