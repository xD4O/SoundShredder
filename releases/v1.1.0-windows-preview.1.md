# Windows standalone preview

Download **SoundShredder-Setup-1.1.0-Windows.exe** from Assets below. Python is included; choose CPU or NVIDIA in the matching setup screen and the audio engine installs automatically. The familiar web interface opens locally in your browser.

This is an **unsigned prerelease** for 64-bit Windows 10/11. Windows can show publisher/SmartScreen warnings. No administrator privileges, manual Python installation, terminal setup or separate CUDA Toolkit are required.

## Start using it

1. Open the EXE and choose **CPU** or **NVIDIA GPU**.
2. Review the storage location/free space and select **Set up SoundShredder**.
3. After setup, select **Open workspace**. Drop in your video/audio, choose a cleanup preset, and preview/download your tracks.
4. Reopen from the **SoundShredder** Start menu shortcut. Use **Close SoundShredder** on the setup screen to stop it; closing the browser tab alone leaves it running.

Allow **4 GiB free for CPU** or **14 GiB for NVIDIA**, plus audio/model storage. The approximately 3.2 GB NVIDIA download expands substantially on disk. This build does not retain duplicate pip downloads. First feature use downloads about 426 MB for layer separation or 1.2 GB for Bubble FX. Internet is needed for these initial downloads; audio processing stays on your computer.

## Included

- Bundled Python 3.13.15 and branded setup with retry, storage information and diagnostics.
- CPU/NVIDIA selection and private engines outside the app directory.
- Video preview, isolated dialogue/music/effects/removed tracks, presets, sessions and aggressive multi-pass water-bubble cleanup.

- Installation/uninstall instructions in **WINDOWS-INSTALL.md**, plus **SHA256SUMS.txt** for asset integrity.

## Storage and removal

The app installs to `%LOCALAPPDATA%\Programs\SoundShredder\1.1.0`; engines and sessions live in `%LOCALAPPDATA%\SoundShredder`. To uninstall, close it, remove the versioned app folder and Start menu shortcut, then remove `runtimes` to reclaim engine space. Keep `data` to preserve sessions. A registered Windows uninstaller is not included yet. See WINDOWS-INSTALL.md for the complete steps.

## Validation and limits

159 automated tests pass on Windows. A prior fresh embedded CPU installation completed real separation and WAV download; the rebuilt package was checked again for startup and source/content integrity. NVIDIA processing exists in the application, but the standalone NVIDIA path has not completed end-to-end validation. This is not yet a signed, broadly tested installer.

Downloads still take time and disk space. Package setup has no cancellation control yet. The update checker checks stable releases only; preview updates are installed manually. Close older source instances before launching standalone. The public stable source release remains [v1.0.3](https://github.com/xD4O/SoundShredder/releases/tag/v1.0.3).
