## Install, create, reopen

1. Quit the older standalone from its menu-bar Quit control or setup page. Keep `~/Library/Application Support/SoundShredder` to retain your engine and sessions.
2. Open the matching DMG, drag **SoundShredder** to Applications, replace the older app if prompted, and eject the disk image. For ZIP downloads, extract and move the app to Applications.
3. Open SoundShredder. Python is bundled; setup automatically installs the CPU engine inside the application window. Existing compatible engines are reused.
4. Drop audio/video, choose a cleanup preset, preview the footage and separate tracks, and save the mix or isolated files through native Save dialogs.
5. Close the application window or use **SoundShredder > Quit SoundShredder** (`Cmd+Q`). Finish/cancel active audio work first. Open it again from Applications or the Dock whenever you return. Opening an already-running copy brings its window forward.

**SoundShredder > Setup and diagnostics** (`Cmd+,`) opens engine settings. **Workspace** (`Cmd+1`) returns to your sessions. Retry opening can recover a failed engine; the desktop host owns the local processes so they shut down after a host crash.

Allow **3 GiB free for setup**, plus the Electron application, models and sessions. First engine/model downloads require internet. Once cached, processing works offline. Audio stays on your Mac.

## Preview notes

**Verified on native Apple Silicon and Intel CI runners:** the packaged applications passed automatic CPU engine setup, real video/audio separation, optional video playback, WAV export, active-job quit protection, duplicate launch and macOS Launch Services reopening, and four launch/close cycles including forced desktop crash recovery with saved sessions retained. Shared regressions passed 173 Python tests and three Electron boundary tests. [Build and test evidence](https://github.com/xD4O/SoundShredder/actions/runs/35167472250). These automated checks do not replace testing a browser-downloaded app through Gatekeeper on a personal Mac.

This release has **no Developer ID signing or notarization**. Browser-downloaded Gatekeeper behavior and broader consumer hardware testing remain separate from automated tests. Only open a download you trust; use System Settings > Privacy & Security > Open Anyway if offered. Do not disable Gatekeeper globally. If macOS reports damage or will not offer an override, report the exact message; a signed release may be required.

Updates are manual through **Help > Check for Electron updates**; the workspace sidebar still checks stable source releases. Replacing the app retains the separate profile. Checksums and platform-specific installation, SSL troubleshooting and uninstall instructions are attached.
