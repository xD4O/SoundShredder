# Windows standalone 1.1.1 — reopen, recover and keep creating

Download **SoundShredder-Setup-1.1.1-Windows.exe** below. This update improves using the installed app after setup: closing, reopening, repeated launches and recovery from a stopped background process.

## What changed

- **SoundShredder** in the Start menu opens an existing workspace or starts the app again after quitting. Your installed engine and saved sessions are reused.
- **SoundShredder Setup** is a separate Start menu shortcut for engine settings, diagnostics and **Close SoundShredder**.
- Launchers check that a saved local address is responding. Stale metadata left by a crash no longer sends you to a dead page or blocks a fresh launch.
- A crashed workspace can restart from the shortcut. If the setup manager crashes, its workspace shuts down instead of remaining orphaned.
- Running the installer again preserves loaded files, repairs missing app files and restores the shortcuts. Setup-state writes retry temporary Windows file-sharing failures.
- The existing dark/mint interface, video preview, isolated tracks, presets and multi-pass bubble cleanup are retained.

## Install or upgrade

1. If an older standalone is running, use **Close SoundShredder** in its setup screen first. Finish/cancel any audio processing before closing.
2. Open the new EXE. For first setup, select CPU or NVIDIA and let it install the engine automatically. Python is included.
3. Use **Open workspace**. On later visits, open SoundShredder from the Start menu.
4. Closing a browser tab leaves the app running. To quit completely, open **SoundShredder Setup** and select **Close SoundShredder**. You can launch it again normally afterward.

Keep the existing engine/data/model folders when upgrading. The app installs to `%LOCALAPPDATA%\Programs\SoundShredder\1.1.1`; engines and sessions remain in `%LOCALAPPDATA%\SoundShredder`. See **WINDOWS-INSTALL.md** for storage, troubleshooting and removal instructions.

First setup requires internet and about **4 GiB free for CPU** or **14 GiB for NVIDIA**, plus model/session space. Engine and model downloads are automatic; a full offline engine is not inside the small installer. Package-install cancellation and automatic preview updates are not implemented.

## Verification and preview limits

**172 automated tests passed on Windows.** The installed EXE was exercised through repeated launch/close/relaunch cycles using a real private CPU runtime, duplicate launches, repeated installer use, missing-file repair, a deliberately terminated workspace, and a deliberately terminated manager. Saved sessions and the existing engine were retained.

This is still an **unsigned preview** for Windows 10/11 x64. Windows may show publisher/SmartScreen warnings. Standalone NVIDIA installation/inference and broader clean-PC testing remain outstanding. Only run downloads you trust. SHA-256 checksums are included.
