# Mac standalone preview

Download the ZIP matching **Apple menu → About This Mac**:

- **SoundShredder-1.1.0-Mac-AppleSilicon.zip** — M-series Macs.
- **SoundShredder-1.1.0-Mac-Intel.zip** — Intel Macs.

Both contain **SoundShredder.app**, bundled Python and the same web interface with a matching setup screen. No Homebrew, terminal setup or separately installed Python is needed. Requires **macOS 12 Monterey or newer**.

**Experimental prerelease: unsigned and unnotarized. Finder launch, Gatekeeper behavior, first-run setup and real inference have not yet been validated on Mac hardware.** Packaging and dependency checks were performed on Windows. macOS may block this preview; only use a download you trust. Do not disable Gatekeeper globally. If it reports a damaged app or offers no supported way to open it, report that result rather than bypassing security controls.

## Start using it

1. Extract the matching ZIP in Finder and move **SoundShredder.app** into Applications or your own `~/Applications` folder.
2. Open the app. Its setup screen opens in your default browser.
3. Review the storage location/free space, then select **Set up SoundShredder** to download the CPU engine automatically.
4. Choose **Open workspace**. Upload video/audio and use the usual cleanup presets, video preview and isolated track downloads.
5. Reopen SoundShredder.app to return. Use **Close SoundShredder** in setup to stop the background process; closing a browser tab alone does not stop it.

Allow **3 GiB free for setup**, plus model/session storage. Each app ZIP is approximately 28 MB; dependencies are downloaded separately. Model downloads are about 426 MB for layer separation and 1.2 GB for Bubble FX. Setup does not retain pip download duplicates. Processing stays local.

## Compatibility

- CPU processing only; Apple Metal/MPS and NVIDIA CUDA are not enabled.
- Bundled Python 3.11.16 for each native architecture.
- Apple Silicon: PyTorch 2.8.0.
- Intel: PyTorch 2.2.2, NumPy 1.26.4 and SciPy 1.14.1.
- SHA-256-verified Python distributions, preserved executable permissions and relative interpreter links.
- 159 automated tests pass on Windows; Mac wheel resolution and Mach-O architecture checks pass. These checks do not replace native Mac testing.

## Storage, troubleshooting and removal

Engines, sessions and logs are under `~/Library/Application Support/SoundShredder`. Close the app before moving or removing it. Move SoundShredder.app to Trash; remove only the support folder's `runtimes` directory to reclaim engine space while preserving `data` sessions. See **MAC-INSTALL.md**, also included as START HERE.txt in each ZIP.

For a certificate error, collect **Setup details**. This app uses its bundled Python/CA store; the separate Python 3.11.9 certificate-repair launcher is for older **source ZIP** installations and should not be copied inside the .app. [Source Mac certificate troubleshooting](https://github.com/xD4O/SoundShredder/blob/main/support/mac/README.md).

Automatic app updates and package-install cancellation are not implemented. Preview updates are installed manually; the update checker checks stable releases only. The public stable source release remains [v1.0.3](https://github.com/xD4O/SoundShredder/releases/tag/v1.0.3).
