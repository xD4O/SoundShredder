Install on Windows.

Windows 10/11 x64 / Electron desktop app. Python is bundled. Engine and model downloads happen inside the app on first use.

WINDOWS SIGNING IS PENDING

The 1.2.2 EXE is unsigned. Edge may show an uncommon-download warning; Windows may show SmartScreen or an unknown publisher. Use the official xD4O/SoundShredder release and compare checksums. See the next page before running the installer.

  1. Download the EXE

    Download Windows EXE from the official release. Read the Windows warning page and verify the downloaded file.

  2. Quit old copies, then install

    Quit an older app or use Close SoundShredder on its standalone setup page. Run the EXE, choose the app installation folder, and finish. No separate Python, PATH edits or administrator rights are needed.

  3. Open and choose storage

    Open SoundShredder from Start or its desktop shortcut. Use Choose folder... for engines, models and sessions, or keep the current location. This storage choice is separate from the app installation folder.

  4. Set up the engine

    Select CPU or a compatible NVIDIA GPU, then Set up SoundShredder. Keep internet connected. Allow at least 4 GiB free for CPU or 14 GiB for NVIDIA, plus the app, models and media. NVIDIA needs a compatible driver; no separate CUDA Toolkit is needed.

  5. Use it, quit and reopen

    The workspace opens automatically. Finish or cancel processing before quitting. Reopen the same shortcut next time; compatible engines and saved sessions are reused.

Uninstall: quit, then use Uninstall SoundShredder in Start or Windows Settings > Apps. Sessions and engines are retained. Full Windows guide and removal instructions.

Understand the warning.

Our official download source is github.com/xD4O/SoundShredder/releases/latest. The Windows installer is still unsigned. The signed Mac release does not sign the Windows EXE.

COMMON MESSAGE

Edge: isn't commonly downloaded.
Windows: Windows protected your PC or an unknown publisher.
These can be reputation warnings, rather than a report of a specific detected threat.

  1. Confirm the exact source

    Use the xD4O/SoundShredder repository and its release Assets. Avoid reuploaded installers and lookalike projects. Open the official release.

  2. Match the checksum

    Download the EXE and SHA256SUMS.txt from the same release. Run Get-FileHash -Algorithm SHA256 -LiteralPath followed by the quoted path to your downloaded EXE. Compare the entire hash against its filename in the checksum file. Windows download verification and warning guide includes a copyable command.

  3. Keep protections enabled

    A matching hash checks the bytes against the published file; it is not a malware scan. A named threat detection or a mismatched hash needs investigation. Do not run a mismatched download or disable security protection.

  4. Choose whether to continue

    Only after verifying and trusting the download, Edge may offer Keep > Show more > Keep anyway; Windows may offer More info > Run anyway. Availability varies. If blocked without an override, use the source version where permitted or contact your administrator.

WHAT WE CAN VERIFY

The official installer passed functional install, uninstall, processing and reopen tests. Those checks are not a security audit, and GitHub hosting alone does not guarantee safety. Windows signing is planned; newly signed downloads can still need reputation.

Install on your Mac.

macOS 13 or newer / Electron desktop app. Current 1.2.2 Apple Silicon and Intel builds are Developer ID signed and Apple-notarized. Mac audio processing uses CPU; Metal/MPS is not enabled.

APPLE SILICON

Download Apple Silicon DMG
For M-series chips. Check Apple menu > About This Mac.

INTEL

Download Intel Mac DMG
For an Intel processor. Use the matching architecture.

  1. Quit any older SoundShredder copy

    Use its Quit command or, for older browser standalones, Close SoundShredder on the setup page. Keep your saved engine and session folders.

  2. Move the app into Applications

    Open the matching DMG, drag SoundShredder into Applications, replace the old app if needed, then eject the disk image. Open SoundShredder from Applications.

  3. Choose storage and set up

    Optionally use Choose folder..., then Set up SoundShredder. Allow at least 3 GiB free, plus the app, models and saved media. Internet is required initially. No Homebrew, separate Python or developer membership is needed to use the app.

  4. Quit and return

    Finish or cancel audio work before quitting. During setup, Cancel setup and quit is available. Reopen from Applications or the Dock; completed sessions remain saved.

IF FINDER REPORTS DAMAGE

The old 1.2.0 preview was unsigned and unnotarized. Download the current 1.2.2 build, check its checksum and architecture, then copy it into Applications. If the warning persists, report the exact message. Do not disable Gatekeeper or remove quarantine as an installation step.

Uninstall: quit and move SoundShredder.app to Trash. Saved data remains in the chosen folder and the user profile. Mac storage, removal and troubleshooting.

Prefer your browser?

The Python source version runs on your own computer at localhost. It uses the same workspace. Choose this route if you want source access; Electron is the easier installation for most users.

Download the source ZIP. Extract the entire folder into a writable location such as Documents. Keep all files together.

WINDOWS SOURCE

Install Python 3.12 from python.org with Add Python to PATH. Run Setup CPU.bat or Setup NVIDIA GPU.bat. When finished, run Start SoundShredder.bat.

MAC SOURCE

Use macOS 12+ and the Python 3.11 universal2 installer. Run Start SoundShredder.command. If Finder will not run the launcher, type bash in Terminal, drag the file into that window and press Return.

  1. Wait for initial setup

    The launcher downloads the CPU or selected NVIDIA engine. First processing also downloads model weights. The browser normally opens http://127.0.0.1:7860.

  2. Keep the launcher window open

    Closing the browser tab does not stop the server. Use Ctrl+C on Windows or Control+C on Mac to stop it. Reopen the same launcher next time.

  3. Repair Mac source certificates if needed

    For Python 3.11.9 with CERTIFICATE_VERIFY_FAILED, run Applications > Python 3.11 > Install Certificates.command, then restart SoundShredder. Keep SSL verification enabled. This repairs the source Python environment, not Electron's bundled runtime.

Complete source installation instructions / Mac source SSL troubleshooting and repair launcher

LOCAL PROCESSING

Media stays on your computer. Dependencies and model weights need internet initially; cached processing works offline. No SoundShredder account or API key is required.

Try it with Akira.

This worked example uses the supplied TestFootage.mp4: approximately 43 seconds, with 48 kHz stereo audio. The screenshots show a completed local Windows source-app run; Electron shares these controls.

  1. Drop the MP4 and remove music

    Choose Remove music: Dialogue 100%, Music 0%, Sound effects 100%. Choose Auto, CPU or NVIDIA GPU, then Separate audio. The example used Auto on an RTX 5090; Mac users choose CPU.

  2. Compare with the footage

    Enable Show video preview. Switch Listen to between Original and Cleaned mix at the same moment. The monitor uses muted video synchronized to the selected audio.

  3. Refine the result

    Audition wanted effects and any voices. If needed, adjust layer levels and click Update mix. Disable Show video preview to return to an audio-only workspace.

AN EXAMPLE, NOT A QUALITY GUARANTEE

This run demonstrates music removal. It does not establish that the Akira clip contains bubbles. Screenshots are included for the walkthrough; the full video and extracted soundtrack are not distributed. Use your own clip to follow along.

Every layer, its own track.

DIALOGUE + MUSIC

Dialogue is the estimated voice layer; it is nearly silent in this example. Music contains the estimated score. A quiet waveform does not necessarily indicate an error.

EFFECTS + REMOVED SOUNDS

Effects contains estimated scene audio. Removed sounds contains material excluded by your latest mix; here it corresponds to the excluded music layer.

  1. Compare one track at a time

    Keep Keep playback position when switching tracks enabled to audition the same moment. Starting a track pauses the others. Preview volume/mute does not change the export.

  2. Download the layer you need

    Use the Download control on Dialogue, Music, Sound effects or Removed sounds. Normal separation prepares them automatically.

  3. Preparing tracks after Bubble FX

    Use Prepare isolated tracks to hear dialogue/music/effects from the original audio before bubble cleanup. This extra separation preserves the cleaned bubble result; download its added layers individually.

LISTEN TO WHAT WAS REMOVED

If Removed sounds includes wanted impacts, ambience or vocal detail, reduce the cleanup or revise the mix. AI separation can leave bleed or reduce wanted sounds.

Choose what stays.

Layer presets set the estimated dialogue, music and effects levels. 0% excludes a layer; 100% keeps it. Intermediate levels reduce it. Change levels after separation and click Update mix to reuse the existing stems.

SEEDANCE / GENJUTSU

Keep a generation whose picture works but soundtrack distracts. Export the video, then drop it into SoundShredder. Choose the preset for the unwanted audio category.

OTHER VIDEO OR MP3 SOURCES

Apply the same workflow to your existing media. Dialogue removal is not an individual-speaker selector, and Effects only can include ambience.

MODEL LIMITS

The layer model can confuse singing, breaths, rhythmic impacts and music. It cannot identify every arbitrary sound or preserve all overlapping detail. Audition the original, cleaned mix and removed material before editing.

Custom text prompts: Bubble FX currently uses four preset sound descriptions. Free-form prompts are not a control in this release.

Target stubborn bubbles.

Use Bubble FX for a distracting bubble, pop or gurgle while trying to retain other effects. This uses AudioSep separately from the dialogue/music/effects model.

  1. Match the unwanted sound

    Choose Water bubbles, Bubbling & popping, Liquid gurgle or Cartoon boing. Start near 85% reduction and restrict the time range when possible.

  2. Try aggressive multi-pass for Water bubbles

    Enable Aggressive multi-pass and start with 2 passes. Each pass rechecks the previous cleaned audio. Try 3 or 4 only if stubborn remnants remain. More passes take longer and can affect similar wanted effects.

  3. Check the combined removed sound

    Compare Original, Cleaned mix and Removed sounds. The latter combines removal across all passes. Reduce strength, narrow the interval or use fewer passes if wanted effects are caught.

  4. Rerun when settings need fresh inference

    Changing sound type, pass count or multi-pass strength/range needs Clean up again, which starts from the saved original in a new session. Single-pass strength/range changes can use Update mix.

EXPERIMENTAL CLEANUP

Multi-pass is available for Water bubbles only. It can reduce persistent remnants, but cannot promise bubble-only removal. Decoded samples outside the chosen interval stay unchanged in the float WAV.

Take it into your edit.

Download a ready-to-use mix or separate layers for more control. Electron uses a native Save dialog; the source web app uses your browser's download behavior.

DOWNLOADCONTENTS
Cleaned WAVAudio retained by your latest settings.
Individual trackDialogue, music, effects or removed audio.
Layer-separation ZIPStems, cleaned mix, removed audio and processing report.
Bubble cleanup ZIPCleaned audio, combined removed sound and report. Additional prepared layers are downloaded separately.

  1. Align the WAV to the original

    Import it into Premiere Pro, DaVinci Resolve or your editor. Place it at the original clip start and mute the original soundtrack. Check sync and transitions.

  2. Keep useful isolated layers

    Put music, voices and effects on their own editor tracks. Build your score or foley around the material you want to retain.

  3. Save before deleting a session

    Download the outputs to your project folder and keep the processing report. Deleting a SoundShredder session removes its local generated files.

AKIRA TIMING CHECK

The example exports preserve the decoded source: 2,052,096 frames / 48,000 Hz / 42.752 seconds / stereo. Timing alignment was checked; these numbers do not measure audible separation quality.

Audio exports, not a replacement MP4. The footage monitor is for preview. Layer separation exports 24-bit PCM WAV; Bubble FX exports 32-bit float WAV. Original media is preserved.

The left panel, explained.

START A NEW SESSION

Click Audio separator at the top of the left panel. The workspace resets so you can import another file; completed saved sessions remain.

RETURN TO SAVED WORK

Click a filename under Recent sessions. The Akira example appears as TestFootage.mp4. Use the refresh control to update the list.

THE X DELETES A SESSION

The x beside a filename removes that local session after confirmation. It is not a close-tab button. Delete this session has the same purpose.

LEAVE WITHOUT DELETING

Start a new session or quit the app. Completed work remains. Click Update mix to save slider changes before leaving; unsaved changes are not a new export.

  1. Finish or cancel active work

    Wait for processing or click Cancel before quitting. During desktop setup, choose Cancel setup and quit if you need to stop.

  2. Quit Electron and reopen normally

    Close its window or use SoundShredder > Quit SoundShredder. Use the Start shortcut or Applications/Dock next time. Opening twice brings the existing window forward.

  3. Stop source and older browser launchers correctly

    Closing a browser tab leaves the server running. Stop the source launcher with Ctrl+C / Control+C; older standalone apps have a Close SoundShredder setup control.

VERSION, GITHUB AND UPDATES

The bottom-left card contains the version, GitHub project link and manual Check for updates button. It checks GitHub when clicked. Desktop Help > Check for Electron updates opens releases.

Storage, updates and help.

CHOOSE YOUR STORAGE

Use SoundShredder > Choose storage folder.... The app remembers the choice. Files are not moved; choose your old folder again to return to its sessions. Keep external drives connected.

SETUP FEELS SLOW

Open Setup details to see package activity. Download bars can pause while packages install. Cancel and retry are available; keep enough free space and an internet connection.

UPDATES ARE MANUAL

Quit and run a newer Windows EXE or replace the Mac app. Saved profiles and compatible engines remain. The sidebar follows numbered releases and ignores prereleases; no silent auto-install is enabled.

FILES AND DEVICES

One file at a time: up to 500 MB / 10 minutes / mono or stereo. Windows supports CPU or compatible NVIDIA CUDA; Mac uses CPU. AMD GPU and Apple Metal/MPS acceleration are not implemented.

Models: first use downloads about 426 MB for Bandit layer separation or 1.2 GB for Bubble FX. Cached runs can work offline. CPU processing may take longer than the clip duration.

Need help? Include the exact release filename, OS/chip, processing mode and error. Use Setup details or Open logs folder; review private paths before sharing. A named malware detection should be reported separately from an uncommon-download warning.
